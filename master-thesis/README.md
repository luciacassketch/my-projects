This is my Master Thesis: _Make it make sense_ - An exploratory study on Word Sense Induction for the terminology industry.

This directory gathers all information needed to replicate the results presented in the thesis on what I call the Wikipedia dataset, which you can find here together with a list of links to the webpages from where the data was extracted. The custom datatset mentioned in the study is private and cannot be shared.

Here, you'll also find the study's abstract, the full analysis of the results on both datasets, and a visualization of the variance of two hyperparameters fine-tuned during the project.

In the "code" sub-directory you'll find all the code needed to run the pipeline I wrote. This code is made public with the license CC BY-NC (visit this website for an explanation of the license: https://creativecommons.org/licenses/by-nc/4.0/).
